GLPI Agent - PCs fora do dominio (manual)
=========================================

Endereco do inventario: https://192.168.1.198:7412/glpi2/
  (IP interno + porta, com validacao de certificado desligada - os PCs de loja
   nao resolvem ti.grupogmais.com pro IP interno.)


>>> NA MAIORIA DOS CASOS voce so precisa de 2 arquivos:

    Repontar agente.bat
    Repontar agente.ps1

O agente JA esta instalado em quase todos os PCs, so ficou apontando pro
endereco velho (que morreu no corte pro Docker em 18/07). O "Repontar" so
troca o endereco e forca um envio - NAO reinstala nada.

Como usar (em cada PC):
  1. Copie os 2 arquivos "Repontar agente.*" para o PC (pen drive / rede).
  2. Botao direito em "Repontar agente.bat" -> Executar como administrador.
  3. Espere terminar. Ele mostra as ultimas linhas do log.
  4. Em alguns minutos confira no portal: Inventario -> PCs Retaguarda / PDVs
     (o aviso "sem inventario ha +Nd" some quando o PC reporta).


>>> SO se o agente NAO estiver instalado (PC novo ou agente removido):

    deploy-glpi-agent.ps1
    Executar Inventario.bat
    GLPI-Agent-1.15-x64.msi   (NAO vem no git; baixe de
                               github.com/glpi-project/glpi-agent/releases/tag/1.15
                               e coloque nesta pasta. Sem ele, o script baixa da
                               internet - so funciona se o PC tiver acesso.)

  Botao direito em "Executar Inventario.bat" -> Executar como administrador.


Trocar o endereco (se um dia mudar): passe -ServerUrl nos .bat/.ps1.
