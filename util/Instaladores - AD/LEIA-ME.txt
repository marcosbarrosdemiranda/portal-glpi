GLPI Agent - instalador para PCs DENTRO do dominio (via GPO)
===========================================================

SERVER do inventario: https://192.168.1.198:7412/glpi2/
  (IP interno + porta 7412, HTTPS com validacao de certificado desligada
   - o cert e para ti.grupogmais.com, nao para o IP, e os PCs de loja nao
   resolvem o DNS interno. E o mesmo endereco da pasta "util/Instaladores".
   A porta 80 do proxy foi removida do nginx - nao use mais.)

Conteudo:
  deploy-glpi-agent.ps1 ...... instala/atualiza o agente a partir do MSI desta pasta
                               e ja RE-APONTA um agente que estava no endereco velho
  run-startup.bat ............ script de startup da GPO (chama o .ps1)
  GLPI-Agent-1.15-x64.msi .... NAO versionado no git. Baixe de
                               github.com/glpi-project/glpi-agent/releases/tag/1.15
                               e coloque aqui (mesma pasta) antes de publicar no SYSVOL.

Dominio: intranet.grupogmais.com

Como aplicar:
  1. Copie os 3 arquivos (ps1 + bat + msi) para uma pasta no NETLOGON, ex:
     \\intranet.grupogmais.com\NETLOGON\glpi-agent\
  2. GPO -> Configuracao do Computador -> Politicas -> Configuracoes do Windows
     -> Scripts (Inicializacao/Encerramento) -> Inicializacao
     -> Adicionar: \\intranet.grupogmais.com\NETLOGON\glpi-agent\run-startup.bat
  3. Vincule a GPO nas OUs dos PCs. gpupdate /force + reboot para testar em 1 maquina.

Trocar o servidor depois:
  O script reescreve a URL no registro + agent.cfg a CADA inicializacao. Para
  mudar o endereco, edite o -ServerUrl na linha do run-startup.bat, republique
  no \\intranet.grupogmais.com\NETLOGON\glpi-agent\: todo PC do dominio se
  re-aponta no proximo boot.

Verificacao:
  - Log no cliente: C:\Windows\Temp\glpi-gpo.log e glpi-agent-install.log
  - GLPI: Ativos -> Computadores (last_inventory_update recente)
  - Portal: Inventario -> PCs/PDVs (o aviso "sem inventario +7d" some em ate 24h)

Nao baixa nada da internet - so usa o MSI da pasta (por isso o MSI tem que estar la).
